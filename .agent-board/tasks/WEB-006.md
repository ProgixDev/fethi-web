## Purpose
Own the shared payment backend: PaymentIntent creation, Stripe Connect Express onboarding, and a signature-verified webhook that is the source of truth for payment state. It is consumed by mobile checkout and the admin finance/KYC UI. Because Stripe Connect runs seller KYC and payouts, there is no custom KYC build here.

## Scope
- Author SCR-004 (payments + payout_accounts; webhook/Connect Edge Functions) and get it Accepted before coding the migration.
- Migration: `payments` + `payout_accounts` tables, written by the webhook via the service role only (no client writes); RLS so buyers/sellers can read only their own rows, staff can read all.
- Edge Function: `payments/config` (returns publishable key + Stripe configured flag; 503 when unconfigured).
- Edge Function: create PaymentIntent for an order — idempotent (reuse existing intent for the same order rather than creating a duplicate).
- Edge Function: Stripe webhook — verify signature, dedupe by Stripe event id (at-least-once delivery), flip `orders.paymentStatus`/`paidAt` on `payment_intent.succeeded`/refund/dispute events.
- Edge Function: Connect Express onboarding link generation + `account.updated` webhook to track seller onboarding/payout-enabled state in `payout_accounts`.
- Deposit handling for LOCATION rentals: capture `depositCents` on order; release/refund flow noted as a follow-up task, not built here.
- Secrets `STRIPE_SECRET_KEY` / `STRIPE_WEBHOOK_SECRET` / `STRIPE_CONNECT_CLIENT_ID` set as Edge Function secrets only — never `NEXT_PUBLIC_*`.
- Regenerate types + MOBILE-SYNC-NOTES entry + copy types to mobile in the same PR.

## Edge Cases
- Duplicate `createIntent` for the same order → reuse the existing PaymentIntent.
- Webhook replay / at-least-once delivery → dedupe by event id (no double state flip).
- Webhook signature verification failure → reject 400, do not mutate.
- Seller not yet onboarded on Connect → block/flag checkout cleanly.
- Refund / dispute events → reflect in `orders.paymentStatus` and `payments`.
- Stripe unconfigured (missing secrets) → endpoints return 503, not 500.
