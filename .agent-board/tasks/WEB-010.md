## Purpose
Admin listing browse/manage plus a moderation queue to hide/remove flagged listings, wired to Supabase behind the existing `src/lib/api.ts` seam.

## Scope
- Listing list / search / detail from real data.
- Staff actions to pause / archive / soft-hide a listing (service role, audited).
- Moderation queue surfacing flagged / reported listings.
- Keep everything behind `src/lib/api.ts` (`listingsApi`); swap implementation, keep interfaces; replace fixtures.
- If a soft-hide / moderation-state column or enum is not already in WEB-003, file an SCR (do not change schema silently).
