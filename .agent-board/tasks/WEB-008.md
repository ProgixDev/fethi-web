## Purpose
Own the trust-and-safety + compliance backend: order-gated reviews, reports (moderation intake), blocked_users, account deletion/export orchestration, and KYC-status read — consumed by mobile and the admin moderation/KYC dashboards.

## Scope
- Author SCR-006 (reviews + reports + blocked_users + deletion/export + kyc-status Edge Functions) and get it Accepted before coding the migration.
- Migration: `reviews` (unique per author/order/target; only after a COMPLETED order), `reports` (targetType `LISTING`/`USER`/`THREAD`/`MESSAGE`; status `OPEN`/`REVIEWING`/`ACTIONED`/`DISMISSED`), `blocked_users`.

- RLS: report authors create reports, staff review all; reviews readable publicly per product policy, writable only by the order's buyer/seller.
- Regenerate types + MOBILE-SYNC-NOTES entry + copy types to mobile in the same PR.

## Edge Cases
- Review without a completed order → rejected.
- Duplicate review (same author/order/target) → rejected by unique constraint.
- Self-report → rejected.
- Delete requested during an active order/dispute → blocked.
- Re-signup with the same identity after deletion → handle cleanly.
