# Questions for next founder/product sync

Genuine product decisions surfaced while building, given a sensible MVP default
so work isn't blocked. Each entry: the question, the default applied, and the
task that raised it.

---

## WEB-022 — Support inbox (issue #77)

- **Should a user be able to mark their own support ticket resolved/closed from
  the mobile app?** Default applied: no — only staff (support/admin role)
  change ticket status. A user can always reply, which reopens a
  resolved/closed ticket automatically.

## WEB-023 — Pre-publish listing moderation gate (issue #68)

- **Should previously-rejected sellers eventually face stricter re-review
  rules (e.g. all their future listings auto-gated, not just the first)?**
  Default applied: no — MVP treats every seller the same; only first-time
  listing creation is gated, no reputation/history-based logic. Revisit if
  moderation volume or abuse patterns warrant it.
