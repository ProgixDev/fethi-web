# SCR-026 — Offer purchase lifecycle hardening

Status: Accepted
Date: 2026-08-24

## Decision

An accepted offer reserves a VENTE listing for 30 minutes. Database unique
indexes allow only one order per accepted offer and one non-terminal sale order
per listing. Expired, unstarted reservations are released when the lifecycle is
next evaluated. Cancelling an unpaid card order cancels its Stripe PaymentIntent
before reopening the listing, preventing a late success from settling a resale.

## Consequences

The Edge Functions remain the only transition surface. A duplicate/racing order
attempt returns a conflict; it never creates a second order, thread, or charge.
