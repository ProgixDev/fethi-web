# SCR-027 — Contact-only rental listings

Status: Accepted
Date: 2026-08-27
Author: Codex
DB reviewer: Web lead
Migrations:

- `supabase/migrations/20260827135354_scr027_contact_only_rentals.sql`
- `supabase/migrations/20260827150000_scr027_contact_only_rental_offers.sql`

## What changes

- Relax `public.listings.listings_pricing_by_type` so an active `LOCATION`
  listing no longer requires `price_per_day_cents`.
- Keep every existing rental pricing/date/deposit column for backward
  compatibility and historical records; no data is dropped or rewritten.
- Make `orders-price-quote` and `orders-create` reject new `LOCATION` checkout
  attempts with `RENTAL_CONTACT_ONLY`. Existing rental orders remain readable.
- Reject new offers on `LOCATION` and prevent acceptance of a legacy pending
  rental offer. Historical offers remain readable and may be withdrawn/rejected.

## Why

The 2026-08-27 client decision replaces managed rentals with simple classified
ads: photos, text, and contact through Messages only. There is no in-app rental
booking, availability calendar, deposit, or rental payment. This also resolves
mobile issue #60, whose marketing page currently advertises the retired model.

## RLS intent

No RLS policy changes. Existing listing ownership and public-read policies stay
authoritative. Order access remains participant-scoped.

## Edge Function

`orders-price-quote` and `orders-create` keep their existing authenticated HTTP
signatures and idempotency behavior. For a `LOCATION` listing they return HTTP
409 with `{ error: "RENTAL_CONTACT_ONLY" }` before pricing or order creation.

## Affected consumers

- Mobile: issue #60; sell flow, listing detail, rental checkout compatibility
  route, map/list cards, and saved rental drafts.
- Web: `/rentals` marketing page and admin listing price labels.

## Rollback / compatibility

The change is backward compatible for reads and existing orders. Reinstating
managed rentals would require a later product decision and SCR; no legacy data
needs restoration because no columns or rows are removed.
